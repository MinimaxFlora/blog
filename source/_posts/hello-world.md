## 为什么开始写博客

拖延了很久，终于把这个博客搭起来了。

想法很简单：把平时折腾的东西记下来。路由器、固件、脚本、各种一时兴起的小项目——做的时候觉得「这我肯定记得」，过两个月再回头看，什么都不剩。写下来，至少下次遇到同样的问题不用从头再来一遍。

## 这里会写什么

- **技术折腾**：OpenWrt、Docker、自建服务、各种踩坑记录
- **脚本与工具**：能省事的小东西
- **日常随笔**：想到什么写什么

不会写得很正式，更像是一个能公开翻阅的笔记本。如果恰好帮到了路过的你，那挺好。

## 这个博客是怎么搭的

有意思的是，搭这个博客本身也算一次折腾：

```bash
# 本地预览
npm run server

# 生成静态文件
npm run build
```

内容用 Markdown 写，推送到 GitHub 之后由 Actions 自动构建、发布到 Pages，域名绑在 Cloudflare 上。整套流程不花一分钱，也几乎不用维护。

---

那么，就从这里开始吧。
